# Cost comparison (drivers, not prices)

Cloud prices, free tiers, WhatsApp conversation pricing and template categories change often and vary by country and plan. **This document deliberately contains no numbers.** Use the linked official pages to price your own volume. Expected scale: ~5–10 staff, hundreds of bookings per month.

| Cost driver        | A. Supabase/PostgreSQL + Vercel (chosen)                                                            | B. Azure SQL Serverless + Azure Functions                                                                           | C. Google Sheets + Apps Script     |
| ------------------ | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| Database           | Managed Postgres plan (project size, storage, backups/PITR add-ons). A small plan is enough.        | vCore-seconds while active (serverless), storage, backup storage; auto-pause saves cost but adds cold-start latency | Included with the Google account   |
| Compute/hosting    | Vercel (or any Node host): plan, function invocations/duration; cron frequency may need a paid plan | Functions consumption plan + a front-end host (Static Web Apps/App Service)                                         | Apps Script quotas (free)          |
| Auth               | Own (no cost)                                                                                       | Entra External ID or own                                                                                            | Google accounts                    |
| Realtime           | Optional (Supabase Realtime, not required)                                                          | SignalR / Event Grid                                                                                                | None                               |
| WhatsApp           | Meta's conversation/template pricing for your country and categories — **same in all options**      | same                                                                                                                | same                               |
| Engineering effort | Lowest: constraints/RLS are declarative                                                             | Medium: locking logic in procedures                                                                                 | Low to start, high rework and risk |
| Operational risk   | Low                                                                                                 | Low–medium                                                                                                          | **High** (no integrity guarantees) |
| Egress/other       | Check bandwidth limits                                                                              | Check egress                                                                                                        | n/a                                |

Pricing pages to consult: Supabase pricing (supabase.com/pricing), Vercel pricing (vercel.com/pricing), Azure SQL Database serverless and Azure Functions pricing (azure.microsoft.com/pricing), WhatsApp Business Platform pricing (developers.facebook.com/docs/whatsapp/pricing), Google Workspace/Apps Script quotas (developers.google.com/apps-script/guides/services/quotas). Verify each when deciding.

Cost levers inside this system: cron frequency (every minute is only needed for timely reminders/retries; every 5 minutes is acceptable if the host charges per invocation), WhatsApp template volume (reminders and KPI nudges are optional and configurable), database size (message text and webhook events are purged automatically).
